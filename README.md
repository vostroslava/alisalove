# LoveOS — Relationship Knowledge Base (MVP)

Это приватный **статический** сайт (без сервера и без “внешней базы”), который:
- импортирует ваш Telegram-export `result.json` прямо в браузере (ничего никуда не отправляет),
- даёт “стену цитат”, редактор “плана отношений”, ежемесячные чек‑ины (метрики 1–10),
- и “галерею” для совместных фото (фото хранятся локально в браузере через IndexedDB).

## Как запустить локально
1) Откройте папку `loveos/` в терминале  
2) Запустите простой сервер:

```bash
python -m http.server 8080
```

3) Откройте в браузере:
`http://localhost:8080/`

## Как задеплоить на GitHub Pages
- Просто залейте содержимое папки `loveos/` в репозиторий (как статические файлы).
- Включите GitHub Pages для ветки/папки.

## Приватность
- Данные (сообщения/цитаты/чекины/фото) сохраняются **локально** в браузере (IndexedDB).
- Для переноса на другой девайс используйте **Export/Import** в разделе Settings.

## Что дальше
Этот MVP сделан как “каркас и логика”. Визуал легко “дополировать” (анимации, графика, типографика, карточки)
— например, через ваш инструмент “Антигравити”.
